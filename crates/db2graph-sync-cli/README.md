# db2graph-sync-cli

**db2graph-sync — an open-source project by Adventa.** <https://www.adventa.com.au>

The `db2graph-sync` binary: run the engine as a standalone process and operate
it (validate, preflight, plan, bootstrap, source-setup, run, status, pause,
resume, approve-mapping, reconcile, evidence, recover, rotate-keys,
audit-verify, keygen, token-hash, about). Pre-release 0.1.0; see the project's
IMPLEMENTATION_STATUS.md and LIMITATIONS.md.
